## mimeo-templates

Templates with built-in workflow to GitHub pages. Designed for use with [pborenstein/mimeo](https://github.com/pborenstein/mimeo). 

Sites built with mimeo and these templates are in the [mimeo-sites](https://github.com/mimeo-sites) organization.

<!-- templates: everything below is also the mimeo-templates.github.io index -->

### [mimeo](https://github.com/mimeo-templates/mimeo) [•](https://mimeo-templates.github.io/mimeo/)
Placeholder template that just shows the <br> `s i t e n a m e`

### [laptopistan](https://github.com/mimeo-templates/laptopistan)  [•](https://mimeo-templates.github.io/laptopistan/)
Placeholder template that displays a picture from picsum.photos

### [markdown-it-simple](https://github.com/mimeo-templates/markdown-it-simple)  [•](https://mimeo-templates.github.io/markdown-it-simple/)
A folder of Markdown files turned into a static site by one build script using markdown-it, with no static site generator.

### [pandoc-simple](https://github.com/mimeo-templates/pandoc-simple)  [•](https://mimeo-templates.github.io/pandoc-simple/)
A pandoc-based single-page Markdown site with no SSG toolchain.

### [pandoc-resume](https://github.com/mimeo-templates/pandoc-resume)  [•](https://mimeo-templates.github.io/pandoc-resume/)
A resume site built from one Markdown file. A GitHub Action renders it to HTML, PDF, DOCX, and plain text, and publishes them behind an index page with your name, objective, and contact details.

### [eleventy-chapbook](https://github.com/mimeo-templates/eleventy-chapbook)  [•](https://mimeo-templates.github.io/eleventy-chapbook/)
An Eleventy v3 starter for chaptered literary sites. Designed for serialized fiction, novellas, and other long-form prose.

### [eleventy-pamphlet](https://github.com/mimeo-templates/eleventy-pamphlet) [•](https://mimeo-templates.github.io/eleventy-pamphlet/)
An Eleventy v3 starter for short literary works: novellas, single-volume fiction, pamphlets. Minimal structure with two layouts.

### [eleventy-prose-blog](https://github.com/mimeo-templates/eleventy-prose-blog) [•](https://mimeo-templates.github.io/eleventy-prose-blog/)
An Eleventy v3 starter for personal prose blogs. Designed for writers who want a polished reading experience: footnote popovers, light/dark theming, RSS feeds, and image optimization.

### [eleventy-tech-blog](https://github.com/mimeo-templates/eleventy-tech-blog) [•](https://mimeo-templates.github.io/eleventy-tech-blog/)
An Eleventy v3 starter for developer blogs. Designed for technical writing: Mermaid diagrams, syntax highlighting, light/dark theming, RSS feeds, and image optimization.

### [eleventy-product](https://github.com/mimeo-templates/eleventy-product) [•](https://mimeo-templates.github.io/eleventy-product/)
A product landing page template built with Eleventy v3: a section-composed homepage where every band of the page is a Markdown file.

### [eleventy-service](https://github.com/mimeo-templates/eleventy-service)  [•](https://mimeo-templates.github.io/eleventy-service/)
A service business landing page template built with Eleventy v3: a section-composed homepage where every band of the page is a Markdown file.
